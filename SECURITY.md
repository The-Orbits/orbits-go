# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately, through GitHub's
[private vulnerability reporting](https://github.com/The-Orbits/orbits-go/security/advisories/new) for this
repository. **Do not open a public issue, discussion or pull request** for a suspected vulnerability.

Include as much of the following as you can:

- the SDK version and your Go version;
- a description of the issue and its impact;
- steps or a minimal example to reproduce it.

We will acknowledge your report within three business days, keep you informed while we work on a fix, and credit you
in the release notes if you would like. Please give us a reasonable amount of time to release a fix before any public
disclosure.

Never include a real API token, environment variable values or other people's data in a report. If a token may have
been exposed, revoke it under Team › Settings › API tokens straight away.

## Supported versions

Security fixes are released for the latest minor version of the SDK.

| Version | Supported |
| ------- | --------- |
| v0.1.x (latest) | Yes |
| Older | No |
